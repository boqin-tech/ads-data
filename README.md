# Ad Data Insights — GitHub Pages starter

This folder contains a static application homepage and privacy policy page for an advertising-data retrieval and analytics tool.

## Before publishing
1. Search and replace `REPLACE_WITH_CONTACT_EMAIL` with an email address you monitor.
2. Replace `REPLACE_WITH_DEVELOPER_OR_COMPANY_NAME` with your real developer or organization name.
3. Confirm the product name `Ad Data Insights` or replace it consistently in both HTML files.
4. Review `privacy.html` carefully and remove or revise anything that does not match your actual data flows, including token handling, storage, retention, logging, analytics, and service providers.
5. Do not claim that the app is affiliated with Google or Meta.

## Publish with GitHub Pages
1. Create a **public** GitHub repository, for example `ad-data-app-site`.
2. Upload `index.html`, `privacy.html`, and optionally this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for deployment. Your URLs should look like:
   - Homepage: `https://YOUR-USERNAME.github.io/ad-data-app-site/`
   - Privacy policy: `https://YOUR-USERNAME.github.io/ad-data-app-site/privacy.html`
7. Open both URLs in a private/incognito window to confirm they are public and load over HTTPS.

## Important
This is a starter template, not legal advice or a guarantee of approval by an advertising platform. Publish only accurate statements about your app. If the app actually stores tokens or advertising reports, describe the real controls and retention practices.
